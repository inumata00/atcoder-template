# AtCoder template

AtCoder の ABC・ARC・AGC 用 C++ テンプレートです。

生成 AI を利用して作成・修正したコードをコンテスト中に使用する場合に備え、公開日時と参照元を確認できる形で公開しています。使用時は、提出コードに次の参照 URL をコメントとして残してください。

```cpp
// Source: https://github.com/inumata00/atcoder-template/blob/main/template.cpp
```

利用前に、必ず最新の [AtCoder 生成 AI 利用ルール](https://info.atcoder.jp/entry/llm-rules-ja) と各コンテスト固有のルールを確認してください。
